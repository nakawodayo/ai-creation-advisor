# AI Creation Advisor

AI Creation Advisor is a client-side application designed to provide AI-powered consultation for creative concerns. This lightweight tool is built using HTML, TypeScript, and CSS, and leverages the OpenAI API to process user queries.

## Project Structure

- **Frontend only**: Static HTML, TypeScript, and CSS.
- **Uses OpenAI API** to process user queries.
- **Stores settings locally** in Local Storage.
- **Three main screens**:
  1. TOP screen (start consultation, settings button).
  2. Dialogue screen (AI interaction, user input, options).
  3. Prompt configuration screen (edit and save AI prompt).
- **Build system**: TypeScript is compiled into JavaScript.
- **Deployment**: Easy to deploy via GitHub Pages or Netlify.

## Getting Started

1. Clone the repository.
2. Run `tsc` to compile TypeScript files into JavaScript.
3. Open `index.html` in a browser to start using the application.

## Deployment

To deploy the application, simply push the contents of the repository to a GitHub Pages or Netlify site.
